# New Features Added

## 1. View Switcher Toggle ⬍⬌
Added a toggle in the header next to the language switcher that allows switching between:
- **Vertical view** (⬍) - Traditional timeline with events alternating left/right
- **Horizontal view** (⬌) - Scrollable horizontal timeline

**Location:** Top right of the header, next to EN/ES language buttons

## 2. Century Markers
Added visual markers that automatically appear at the start of each century:
- "1st Century", "2nd Century", "3rd Century", etc.
- Styled with gradient badges
- Animate on appear with fade-in scale effect
- Work in both vertical and horizontal orientations

## Features:
- **Dynamic orientation switching** - Changes take effect immediately
- **Smooth scrolling** - Horizontal view has custom styled scrollbar
- **Responsive design** - Works on mobile and desktop
- **Century grouping** - Events automatically grouped by century with markers
- **Modular architecture** - Easy to extend with more view options

## How It Works:
1. Click the ⬍ button for vertical timeline (default)
2. Click the ⬌ button for horizontal scrolling timeline
3. Century markers automatically appear based on event dates
4. All functionality preserved in both views (click events, filters, sidebar)

The timeline now supports future expansions like diagonal, circular, or other creative layouts!
